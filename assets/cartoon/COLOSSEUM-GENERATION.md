## Rendering quality correction

The source image remains unchanged. Retina magnification was using nearest-neighbor sampling because Phaser 3.90 defaults `pixelArt` to `scale.zoom !== 1`; our physical-resolution canvas uses `zoom: 1 / DPR`. This implicitly disabled antialiasing and set canvas CSS to `image-rendering: pixelated`, despite the existing `antialias: true` setting. The game now explicitly sets `render.pixelArt: false`. `check:arena-quality` verifies LINEAR texture filters for both maps and all character atlas pages at DPR 1, 2, and 3, and rejects pixel-art CSS. Matched before/after Retina crops are saved under `output/arena-quality/`. This fixes display-induced blockiness without claiming additional native image resolution.
